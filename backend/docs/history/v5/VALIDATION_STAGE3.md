## 검증 중 수정한 사항

반대 방향 동시 실행에서 계좌 refresh가 연관 사용자 행까지 잠그는 문제가 재현됐다. Account.owner를 지연 로딩으로 바꾸고 소유권은 프록시를 지원하는 getter로 확인하여, 계좌 잠금이 수취 사용자 잠금으로 확장되지 않도록 수정했다. 이 변경 후 기존 잔액 조회의 소유권 비교도 getter를 사용하도록 수정했다.

날짜 경계 테스트의 SQL 리터럴은 실행 환경 시간대에 따라 다르게 해석될 수 있어 UTC Instant를 파라미터로 전달하도록 수정했다.

V1~V6 기존 migration 파일 6개(SQL 5개 + Java V4)는 2차 작업본과 바이트 단위 동일함을 확인했다. V7만 추가했다.

## 한계

H2의 동시성 통과는 실제 PostgreSQL의 잠금·격리·장애 동작을 보장하지 않는다. PostgreSQL 및 프론트 통합은 사용자 결정대로 마지막 단계에서 검증한다. Windows 사용자 PC, 실은행망, 부하·다중 서버·DB 재시작/장애 조치는 이번 검증 대상이 아니다.

요청 제한은 단일 서버 메모리에서만 동작한다. 구 API 호환 경로에는 단계형 비밀번호 재확인이 강제되지 않는다. 계좌 출금 등록·PIN·한도는 후속 단계이며 현재 구현된 것으로 간주하지 않는다. 과거 구 송금에 v2 저장 결과를 소급 생성하지 않는다.
