- 검증일: 2026-10-04 (KST)
- Java 17.0.20 / Maven 3.9.9
- Maven 로컬 캐시를 사용한 오프라인 `clean package` 성공

- 새 PIN 단독 승인 통합 테스트 5개 추가, 기존 가입·이체 테스트를 PIN 단독 계약으로 수정
- 기존 H2 및 H2 기반 마이그레이션 테스트 포함. PostgreSQL 서버 및 실제 프론트 브라우저 연동 검수는 미실행

## 확인한 변경 동작

- 비밀번호 없이 PIN으로 이체 승인 및 실행, 승인 방법 ACCOUNT_PIN 반환
- 정기예금·정기적금 가입과 동일 요청 재전송 시 단일 출금
- 잘못된 PIN의 실패 누적 및 4회 잠금, 이체·가입 간 실패 횟수 공유
- PIN 누락·형식 오류·잘못된 PIN·다른 사용자 계좌/preview 거부
- PIN 실패 시 계약·잔액·성공 영수증 생성 안 됨
- 승인 요청 1분 30회 제한 및 Retry-After
- F7 비밀번호 생략 거부, F7 비밀번호 차단 중 PIN 이체 승인은 허용
- 구버전 선택 password 값이 PIN 승인에 사용되지 않음
- 기존 실행 재시도, 거래 rollback, 예적금 추가 납입·해지 회귀 테스트 통과
