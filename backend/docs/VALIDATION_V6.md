## 검증 범위

- 일반 H2 JPA 환경 및 H2 PostgreSQL 호환 모드/Flyway V1~V12/스키마 validate 환경.
- SMS 모의 확인·약관·중복 가입 처리·기존 API 차단.
- 로그인 3회 잠금, 동시 오류의 카운트 보존, 정상 로그인 초기화, IP 제한.
- 10분 유휴/8시간 절대 만료, 조회 폴링과 연장 구분, 로그아웃.
- 계좌 확인 기반 복구, 일회용 복구 코드, 목적/만료/보안 버전 검증, 동시 복구 토큰 소모.
- 비밀번호 규칙/재사용, 프로필 변경 우회 차단·재인증 제한, 다른 사용자의 연락처 권한 거부.
- 계좌 개설 PIN·약관·재전송, PIN 4회 잠금·등록 전화번호로만 재설정.
- 계좌 조회·커서·설정·수취 계좌·한도, 소유권, 이체 승인·중복 실행 방지·동시 한도·원장 실패 롤백.

DB 제약 위반을 의도적으로 발생시키는 롤백 테스트는 로그에 SQL ERROR를 남깁니다. 테스트의 예상 실패 경로이며 전체 실행 결과는 성공입니다.

## 이전 테스트와의 관계

v5의 구 API·선택 휴대폰 가입·시간제 PIN 잠금 등을 기대하는 계약 테스트는 `test-history/v5-contracts`에 원본을 보관했습니다. Maven 테스트 대상에서 제외하고 v6 정책의 통합 테스트로 교체했습니다. 예적금·암호화·마이그레이션 테스트는 새 가입/계좌/PIN 경로에 맞춰 유지했습니다. 따라서 이번 73개는 이전 97개를 그대로 모두 실행한 결과가 아닙니다. 구 계약을 유지해야 한다는 의미도 아닙니다.

## 검증하지 않은 항목

실제 PostgreSQL 서버·실제 DB 병합, 사용자 컴퓨터에서의 Maven 실행, 프론트 브라우저 E2E, 실제 문자/메일 발송·명의 확인·인증서/OTP, 실제 KB 전체 화면과의 동일성, 운영 부하 테스트는 이번 검증 범위에 포함하지 않습니다. 백엔드의 API 테스트를 프론트 UI 완료로 해석하면 안 됩니다.

## 배포 유의사항

기존 지속 DB에는 V12 마이그레이션이 필요합니다. 기존 세션은 폐기되며 PIN 잠금이 자동 해제되지 않습니다. 기존 사용자에게 정보 보완과 복구 코드 준비 절차를 안내해야 합니다. 기본 메모리 DB로 재실행하면 데이터가 보존되지 않습니다.
