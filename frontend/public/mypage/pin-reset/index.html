계좌 비밀번호 재설정

잊어버렸거나 잠긴 계좌 비밀번호를 다시 설정합니다.

계좌 비밀번호를 잊었거나 4번 틀려 잠겼을 때 사용합니다. 잠긴 비밀번호는 시간이 지나도 풀리지 않습니다.

불러오는 중…

본인 확인 방법

모의 연락처 확인입니다. 실제 문자는 발송되지 않으며 실명·명의 확인이 아닙니다. 인증번호는 시연 담당자가 확인해 알려 드립니다.

한 번 사용한 코드는 다시 쓸 수 없습니다.

숫자 4자리. 반복·연속 숫자, 휴대폰 번호에 든 숫자 불가

재설정하면 모든 로그인이 해제되고 발급한 복구 코드도 폐기됩니다. 다시 로그인해 주세요.

계좌 비밀번호를 다시 설정했습니다. 모든 로그인이 해제되었으니 다시 로그인해 주세요. 복구 코드도 새로 발급해 두세요.

로그인
로그인도 할 수 없나요?

먼저 비밀번호 재설정 또는 로그인 잠금 해제로 로그인할 수 있는지 확인해 주세요. 계좌 비밀번호가 잠겼고 복구 코드도 없다면 이 시연 환경에서는 스스로 복구할 수 없습니다. 시연 운영자에게 테스트 환경 확인을 요청해 주세요.
